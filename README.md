# AgriAssist AI

An intelligent agricultural assistant designed to empower farmers and agricultural researchers. AgriAssist AI uses multimodal AI to analyze crop images, identify plant diseases, provide actionable farming recommendations, and deliver advice through text and clear voice audio.

Live Demo: https://agri-assist-ai.streamlit.app

---

## Features

- Image Analysis: Upload plant/crop photos to detect diseases, pest infestations, or nutritional deficiencies.
- Multimodal Intelligence: Powered by Google's Gemini API for context-aware agricultural insights.
- Voice Guidance: Integrated Google Text-to-Speech (gTTS) generates spoken responses for accessible audio delivery.
- Secure Secrets Management: API keys are protected using Streamlit Cloud Secrets.

---

## Tech Stack

- Frontend / Framework: Streamlit
- AI Model: Google Gemini API (google-genai)
- Audio Processing: gTTS (Google Text-to-Speech)
- Image Processing: Pillow (PIL)
- Language: Python 3.10+
